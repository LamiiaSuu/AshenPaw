# Ashen Paw

Ein 2D-Soulslike in Pixel Art mit einem Wolfshund als Hauptcharakter, inspiriert von Hollow Knight und Blasphemous.

Im Mittelpunkt stehen präzises Movement, Nahkampf und Bosskämpfe. Geplant ist ein Schwert mit der Seele des Meisters, mit dem Dämonen dauerhaft besiegt werden können. Die Geschichte soll vor allem über die Umgebung erzählt werden.

## Steuerung

| Aktion | Tastatur / Maus | Xbox-Controller |
| --- | --- | --- |
| Bewegen | A / D oder Pfeiltasten | Linker Stick / Steuerkreuz |
| Springen / Walljump | Leertaste | A |
| Ducken | S / Pfeil runter / linke Strg | Stick / Steuerkreuz runter |
| Kamera hoch | W / Pfeil hoch halten | Linken Stick / Steuerkreuz hoch halten |
| Kamera runter | Geduckt bleiben | Geduckt bleiben |
| Dash | Linke Shift / K | B |
| Light Attack / Combo | Linksklick, für die Combo erneut klicken | X, für die Combo erneut drücken |
| Parieren | E | RB |
| Konterbiss / Visceral Attack | Linksklick nah am parierten Gegner | X nah am parierten Gegner |
| Heavy aufladen | Rechtsklick halten | Y halten |
| Schnappbiss nach Light Attack | Rechtsklick kurz tippen | Y kurz tippen |
| Biss mit Seitenwechsel nach Light Attack | Rechtsklick halten | Y halten |
| Dash-Strike | Im Dash Linksklick | Im Dash X |
| Schnappbiss im Dash | Im Dash Rechtsklick kurz tippen | Im Dash Y kurz tippen |
| Biss mit Seitenwechsel im Dash | Im Dash Rechtsklick halten | Im Dash Y halten |
| Rundumangriff in der Luft | In der Luft Linksklick | In der Luft X |
| Luftbiss zum nächsten Gegner, ohne Ziel Luftdash | In der Luft Rechtsklick | In der Luft Y |
| Sturzangriff | Beim Luft-Rechtsklick nach unten drücken | Beim Luft-Y Stick / Steuerkreuz runter |
| Dummy / Skelett wechseln | G | Nicht belegt |
| Debug-Modus ein- / ausblenden | H | Nicht belegt |
| Pausenmenü | Esc | Start / Menü-Taste |

Der Heavy wird bei voller Ladung automatisch ausgeführt. Rundumangriff und Luft-Rechtsklick sind jeweils einmal pro Sprung möglich. Der Debug-Modus zeigt Zustände, Werte, Gegner-HP und Hitboxen und bietet Unverwundbarkeit, Unsichtbarkeit für Gegner und einen Reset zum Startpunkt. Unlimited Stamina ist erstmal nur ein Platzhalter.

## Combos

Pfeile zeigen die Reihenfolge. Die meisten Inputs können gebuffered werden.

| Combo | Tastatur / Maus | Xbox | Description |
| --- | --- | --- | --- |
| 3er Light Combo | Linksklick → Linksklick → Linksklick | X → X → X | Der dritte Schlag macht am meisten Schaden und springt ein Stück nach vorne. |
| Any Lights → Schnappbiss | Linksklick(e) → kurz tippen | X → Y kurz tippen | Schneller Biss als alternativer Finisher. |
| Light → Biss mit Seitenwechsel | Linksklick → während des Schlags Rechtsklick halten | X → während des Schlags Y halten | Am Gegner vorbeiziehen und beim Umdrehen zurückbeißen. Dabei können Movement-Inputs die Seite bestimmen.|
| Dash → Dash-Strike | Shift / K → im Dash Linksklick | B → im Dash X | Früh drücken, wenn du den Gegner auf dem Weg durch ihn treffen willst. Die Hitbox reicht auch nach vorne. |
| Dash → Heavy | Shift / K → im Dash Rechtsklick kurz tippen | B → im Dash Y kurz tippen | Bricht den Dash früh für einen kurzen Biss nach vorne ab. |
| Dash → Biss mit Seitenwechsel | Shift / K → im Dash Rechtsklick halten | B → im Dash Y halten | Früh halten, um noch während des Dashs in den Seitenwechsel zu gehen. Dabei können Movement-Inputs die Seite bestimmen. |
